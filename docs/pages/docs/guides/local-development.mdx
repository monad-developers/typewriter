# Local development [Run your app against a local chain]

Dev mode runs your app with nothing but a Postgres database. Typewriter starts a local chain, deploys your contract to it, and makes Anvil's first account the root, scheduler, and relayer.

```ts [src/index.ts]
const typewriter = await createTypewriter(Token, {
  dev: true,
  database: { url: process.env.DATABASE_URL! },
});
```

Dev mode needs `anvil` from [Foundry](https://getfoundry.sh) v1.8.0 or later on the `PATH`.

## Anvil

Each dev process starts its own Anvil chain and stops it when the process stops, with nothing saved between runs. The chain is set up to behave like Monad:

- Monad's EVM rules, with `--network monad`, and the `MonadTen` hardfork.
- A block every 250 milliseconds.
- Blocks finalize about two blocks behind the latest, so mutations reach `finalized` within a second.

Anvil listens on a random port, so several dev processes can run at once. Typewriter logs the RPC URL and the deployment at startup:

```text
INFO  Started Anvil rpc_url=http://127.0.0.1:35585 chain_id=31337 account=0xf39Fd6e51aad88F6F4ce6aB8827279cffFb92266
INFO  Created deployment deployment=typewriter_dev_<random> chain_id=31337 address=0x... transaction_hash=0x...
```

## Automatic deployment

At startup, Typewriter builds your contract and deploys it to the new chain. There's no deploy script to run, and changes to your Solidity take effect on the next start.

Dev mode fills in `deployment`, `root`, `scheduler`, `relayer`, `chainId`, `rpcUrl`, and `hardfork` for you. Setting `deployment`, `root`, `scheduler`, `relayer`, `chainId`, or `rpcUrl` along with `dev` is an error.

## Database

Each dev process gets its own deployment, `typewriter_dev_<random>`, and with it its own Postgres schema of the same name, which it drops when the process stops.

## Pruning

Anvil keeps only recent history in memory, so a dev chain that runs for hours doesn't keep growing:

- State for the last 64 blocks, about 16 seconds.
- Transactions and receipts for the last 1024 blocks, about 4 minutes.

Reads of older blocks fail. Typewriter doesn't need them, but tools that query old blocks, such as `cast` with an old `--block`, won't find them.

## Switching to production

Read `dev` from the environment so the same code runs locally and in production:

```ts [src/index.ts]
const dev = process.env.NODE_ENV !== "production";

const typewriter = await createTypewriter(Token, {
  dev,
  ...(dev
    ? {}
    : {
        deployment: process.env.DEPLOYMENT,
        root: process.env.ROOT_ADDRESS,
        scheduler: privateKeyToAccount(process.env.SCHEDULER_PRIVATE_KEY),
        // Optional: sends the settlements and pays their gas. Defaults to `scheduler`.
        relayer: process.env.RELAYER_PRIVATE_KEY
          ? privateKeyToAccount(process.env.RELAYER_PRIVATE_KEY)
          : undefined,
        chainId: Number(process.env.CHAIN_ID),
        rpcUrl: process.env.RPC_URL,
      }),
  database: { url: process.env.DATABASE_URL },
});
```

See [deployment](/docs/production/deployment) for the production config.
