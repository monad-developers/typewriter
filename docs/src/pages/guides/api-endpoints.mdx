# Add API endpoints

Wrap the Typewriter handle in the HTTP routes your frontend calls: a submit
endpoint, the signing domain, reads, and a status stream.

:::warning
Documentation is under construction — this is a placeholder page. Content will
be filled in over the coming iterations.
:::

## Planned contents

- Wiring routes around the handle returned by `createTypewriter`
- A submit endpoint: decoding a signed mutation and calling
  `typewriter.execute`
- Exposing the EIP-712 domain for clients to sign against
- Read endpoints backed by `typewriter.state` and `typewriter.schema`
- Streaming lifecycle status to clients over SSE or WebSocket with
  `typewriter.on`
- Validation, error shapes, and rate limiting at the edge
